# Customer Churn Analysis & Prediction

This project focuses on understanding customer churn in the telecom industry using Python, SQL, and Power BI. I analyzed customer data to identify patterns related to contract types, tenure, payment methods, and monthly charges.

I also built machine learning models using Logistic Regression and Random Forest to predict customers who may be at risk of leaving. The findings are presented through a Power BI dashboard, along with recommendations to improve customer retention.

**Tools:** Python, SQL, SQLite, Pandas, Scikit-learn, Power BI

**Dataset:** [Telco Customer Churn – Kaggle](https://www.kaggle.com/datasets/blastchar/telco-customer-churn)
